# Contributing

- Keep AgentWatch observe-only; do not merge features that control an agent.
- Prefer Node standard library APIs.
- Preserve local-only behavior and secret redaction in every output path.
- Run `npm install`, `npm run typecheck`, and `npm test`.
- Add tests for adapters, telemetry, security analysis, evaluation, or reporting changes.
- Document user-facing commands and configuration in `README.md` and `docs/architecture.md`.
